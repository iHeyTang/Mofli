# Companion actions

Bloub: 66 actions. Mew: 66 actions. Spatial: 60 actions.

Each scene has four new actions. IDs are shared across rigs. Existing indices remain unchanged: new 2D indices 14-65, new 3D indices 8-59. The original Bloub autoplay reference sequence retains its 14 original entries.

Public exports: `companionActions`, `companionMotion` from `@mofli/grove`. These are deterministic procedural body/head scores, bound to each rig geometry; not sprite images.
