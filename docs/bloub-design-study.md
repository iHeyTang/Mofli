# Bloub 研究：灵动来自受约束的运动空间

研究日期：2026-09-08。核对 main 时的提交为 `b4bb3c1b5f93c7b87a2e8d620f667c4093d97749`。阅读了 shape / engine / face / eyefit / states / math、架构与测量文档，以及 engine / skins / face 的回归测试；没有在本地执行 Bloub 的测试，因此对其覆盖范围的描述来自源码，而非复测结论。

结论：64 是采样分辨率，并不是“不会崩”的保证。Bloub 在一个范围明确的角色模型里，通过统一几何表示、时间连续性、约束预计算和回归测试共同维持质量。Mofli 应借鉴这些机制，形成 **Rig = 结构 + 控制空间 + 几何约束 + 绑定准备 + 连续性约定 + 验收测试**。

## 1. 一致拓扑比采样数量更重要

[shape.ts](https://github.com/jeremy-prt/bloub/blob/b4bb3c1b5f93c7b87a2e8d620f667c4093d97749/src/bot/shape.ts) 使用统一角度和固定数量的半径，插值同方向的半径，而不是猜测两个任意 SVG 路径的点如何对应。它把轮廓、旋转、缩放与位移分别表示；旋转取最短方向，避免 +170° 到 -170° 绕一大圈。最终用平滑曲线连接采样点。

能保证的是“对应关系清楚”。任意输入半径、剧烈相邻差异、含洞或多分支的轮廓仍可能违背模型假设。曲线平滑也不能一般性地证明无自交。

Mofli：软体 Rig 保留固定拓扑，但只允许受约束的低频轮廓族；机械 Rig 保持独立部件。64 不属于全局协议。以后开放任意轮廓导入前，应校验正半径、相邻变化、曲率/自交与五官空间。

## 2. 五官跟随曲面，才有体积感

[face.ts](https://github.com/jeremy-prt/bloub/blob/b4bb3c1b5f93c7b87a2e8d620f667c4093d97749/src/bot/face.ts) 把双眼放在球面上，通过切平面的正交投影产生位置、压缩、倾斜和可见性。两眼并非平面上等宽的图形简单左右平移。轮廓变化后又按实际方向半径修正位置。

Mofli：这属于 soft-body Rig 的曲面绑定能力，不应强加给机械屏幕型角色。本轮先实现共用身体坐标系及受约束视线；**尚未实现完整球面切平面投影**。下一步应以通用曲面绑定函数支持球面/平面等不同模型，并测量眼距、可见性和投影退化。

## 3. 约束计算的位置决定是否抖动

[eyefit.ts](https://github.com/jeremy-prt/bloub/blob/b4bb3c1b5f93c7b87a2e8d620f667c4093d97749/src/bot/eyefit.ts) 说明：仅校正眼睛中心不足以防止眼睛边缘越界。运行时不断找“当前最危险的边缘/眼睛”会让约束对象来回切换，引起抖动。它选择在加载时求每个形状、状态和表情组合的双眼共同位移，再插值修正值。共同位移保留眼距，独立限制两眼则可能破坏脸的关系。

这不是“所有输入都安全”的通用求解器：当前表基于内置目录，未知轮廓回退到零修正。

Mofli：增加可扩展 `Rig.prepare(skin)`，把静态绑定放到皮肤边界。软体 Rig 采用自己的保守解析安全区，覆盖整个允许的时间扰动和面部包围范围，预先收紧共同视线幅度；不在每帧单独挤压或搬动某一只眼睛。拒绝无法提供空间的皮肤。当前方案牺牲部分极端视线幅度以保留稳定性，不复制 Bloub 的求解器。

## 4. 连续性必须覆盖“半途改主意”

[engine.ts](https://github.com/jeremy-prt/bloub/blob/b4bb3c1b5f93c7b87a2e8d620f667c4093d97749/src/bot/engine.ts) 对已经在进行的过渡，冻结当前混合姿态作为下一次起点；否则从上一个目标姿态出发会跳变。对正常状态切换则允许离开的动画继续运动。视线连续重定向也从当前插值值出发。

Mofli：新增皮肤、心情、状态和行为变化的快照过渡，以及可连续重定向的视线曲线。测试在 25ms 间隔连续换皮肤，切换时画面必须相同。当前保证是位置连续（C0），**不是速度连续（C1）**；目前离开状态用快照，尚未实现完整的动态双姿态混合。通用 SVG fallback 只能混合兼容命令结构；拓扑不兼容时交叉淡化，不强行 morph。

## 5. 克制与时间设计构成“灵动”

[测量说明](https://github.com/jeremy-prt/bloub/blob/b4bb3c1b5f93c7b87a2e8d620f667c4093d97749/docs/measurements.md) 强调：身体过渡不普遍使用弹簧和超调。参考角色的生命感主要来自视线、眨眼与极小扰动。源码中状态切换的遮掩眨眼、确定性眨眼日程，以及指针接管时抑制自主视线，都是经过设计的节奏。

Mofli：去掉原先阈值开闭式眨眼，改成连续眼睑曲线；视线有界缓入，拖拽恢复改为按时间步长计算，避免高刷新率改变手感。独立 Behavior 关键帧必须在 neutral 开始/结束，输入为纯数据，通道有边界。当前预设行为是单动作、可打断、带优先级，不是完整行为树或多轨混合系统。

## 6. 遮罩和绘制顺序也是绑定规则

[架构说明](https://github.com/jeremy-prt/bloub/blob/b4bb3c1b5f93c7b87a2e8d620f667c4093d97749/docs/architecture.md) 使用眼睛遮罩孔、身体底色衬层以及轨道前后分层，避免轮廓外溢、环绕物穿过眼睛等问题。遮罩能处理裁切，无法修正脸挤到边缘后的难看效果，仍需几何约束。

Mofli 当前 SVG 渲染器支持四种基础图元，尚无 mask / clip / group 资源系统。后续应提供类型化局部资源、实例命名空间和稳定层级，禁止通过原始 SVG 字符串绕过协议。该能力与表情/骨架约束配合，而不是拿 clipping 掩盖不合格皮肤。

## 7. 测试“没有抖”和“没越界”，而不只是快照相同

[skins.test.ts](https://github.com/jeremy-prt/bloub/blob/b4bb3c1b5f93c7b87a2e8d620f667c4093d97749/src/bot/skins.test.ts) 检查完整眼睛轮廓、时间变化和多种皮肤/状态/表情组合，且度量来回折返，避免只测试一个时刻。engine 测试覆盖过渡重入与可重复采样。

Mofli 新增：参数极值 × 表情 × 视线 × 拖拽 × 按压 × 多时间点的完整五官采样；连续中断时的零位移检查；眼睑步进和视线方向检查；prepare 的执行次数及失败回退。它们是有限范围的回归检查，不能声称证明任意插件永不出错。

## 分层结论

- 引擎：确定性时钟输入、过渡机制、优先级、渲染资源、生命周期。
- Rig：拓扑、部件关系、坐标变换、动作通道、绑定算法、安全域及其测试。
- Skin：只在 Rig 允许的设计空间内提供外观数据。
- Behavior：在允许的控制通道中编排随时间变化的数值。
- 演示页：展示/调整上述能力，不能成为运行引擎的前置条件。

独立实现，不继承参考角色的测量常数、图形、预设动作或视觉身份。下一步重点应是 Rig 级姿态混合、球面/平面绑定和 SVG 局部资源体系，而不是继续堆叠工作台功能。

## 后续实现进展
