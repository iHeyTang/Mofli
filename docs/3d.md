# 3D 宠物：WebGL

Mofli 按宠物维度固定渲染方式：2D 使用 SVG，3D 使用 WebGL。Studio 先选择 2D / 3D，再选择该类型下的角色与饰品。新建宠物沿用当前类型。

## 使用

```ts
import { createPet } from "@mofli/core/browser";
import { spatialRig, spatialSkin } from "@mofli/grove/rigs/spatial";

const pet = createPet({ container, rig: spatialRig, skin: spatialSkin });
pet.setPose({ yaw: 0.4, expression: 5 });
// 组件卸载时调用
pet.destroy();
```

`@mofli/core/scene3d` 提供无 DOM 的几何、相机、材质和 `defineSpatialRig`。3D 骨架实现 `sampleScene(input)`，通过 `PetEngine.sampleScene` 产生场景。`@mofli/core/spatial-browser` 的 `createSpatialRenderer(container)` 使用 WebGL 绘制。

3D 不再提供 SVG 投影、SVG 导出、自动选择或运行中切换渲染器。`PetEngine.sample()` 仅用于 2D；对 3D 调用会报错。原版 2D 的 Frame、SVG、饰品及导出保持原行为。

## 模型与材质

3D 模板包含 Mallow、Pip、Pebble 的果冻版本，沿用原版轮廓和表情，提供 19 个表情、8 个动作、6 个基础形状。饰品使用场景节点，与身体共同参与深度测试和遮挡。

WebGL 使用顶点法线、逐片元光照和深度缓冲。`transmission` 控制屏幕空间透射，`transmissionRoughness` 控制被身体遮挡的几何的散射模糊；支持深度纹理时逐像素区分前景与背景。离屏或不可见表面不会被重建，这不是完整的体积光学模拟。

表情、基础形状和颜色在 0.38 秒内连续过渡。身体与眼睛使用对应的顶点结构，动作切换继承当前姿态和速度；中途再次切换会从正在显示的中间状态接续。只切换表情时保留动作进度。该逻辑位于 3D 骨架，Studio 与导出的运行包共用；暂停时修改参数会完成短暂过渡后停住。

闭眼在连续网格上过渡到圆头弧形眼睑。跳跃包含蓄力、抛物线飞行、衰减回弹和局部软体变形。减少动态模式保留静态预览。

## 运行与交付

运行 `npm run dev -- --port 14517`，工作台为 `/`，独立 3D 预览为 `/spatial.html`。预览支持鼠标、触摸、键盘及正交/透视相机。

CLI 使用 `mofli init my-pet --dimension 3d`。导出的独立运行包使用 `mountPet(container)`，配置通过 JSON 保存和导入。3D 不导出静态 SVG。

设备无法创建 WebGL 时显示明确提示；上下文丢失时提示刷新重试，不回退为 SVG。Studio 缩略图共用一个临时 WebGL 上下文，分批生成 PNG 并使用有界缓存；无法渲染时显示预览不可用。

## 饰品与参数

3D 饰品使用独立的 `Attachment` 资源，通过 `defineSpatialAttachment` 声明 `mount`、`colors`、数值 `parameters`、显示 `labels` 与纯函数 `sampleScene`。资源包仍用 `attachments` 注册，完整宠物配置在每个饰品实例的 `colors` 和 `parameters` 保存覆盖值。颜色不会从宠物皮肤继承；更换皮肤会保留已佩戴饰品的设置。

礼帽提供帽身、帽带、尺寸、悬浮高度和倾斜；小芽提供叶片颜色、尺寸、芽长和悬浮高度；星尘环绕提供星光与微尘配色、粒子大小、环绕范围、飘动速度、微尘密度、拖尾长度和柔光强度。Studio 根据饰品声明生成控件。3D 骨架逐帧输出挂载节点，饰品继承身体的旋转和形变，并参与同一 WebGL 深度与透射计算。

```ts
import { defineSpatialAttachment } from "@mofli/core";
import { ellipsoid3D } from "@mofli/core/scene3d";
const geometry = ellipsoid3D([0.18, 0.15, 0.18]);
export const pearl = defineSpatialAttachment({
  id: "pearl",
  mount: "head.crown",
  colors: { body: "#dfcdab" },
  labels: { body: "球体", size: "尺寸" },
  parameters: { size: { min: 0.6, max: 1.4, default: 1 } },
  sampleScene({ time }, p, colors) {
    return [
      {
        id: "pearl",
        geometry,
        material: { color: colors.body },
        transform: { position: [0, 0.22, 0], scale: [p.size, p.size, p.size] },
      },
    ];
  },
});
```

使用 `mofli init my-pearl --dimension 3d --type attachment` 创建独立饰品项目。原型时期存于 `rigConfig.hat/ears/orbit` 和 `skin.colors.accessory` 的完整配置，在 `PetRegistry.resolve` 时迁移为独立饰品实例；需注册 `spatialParts`（Studio 和导出包已注册）。新配置不再包含这些身体字段。原版 2D 饰品保持原协议。

星尘环绕由圆润星芒、短拖尾和具有生灭周期的微尘组成，沿倾斜的立体轨迹穿行，参与身体遮挡与果冻透射。粒子位置由显式时间确定，复用几何，暂停或减少动态时保持静态；密度只调整微尘数量。沿用 `spatial-orbit` 资源 ID，旧配色与速度配置继续有效。饰品可通过 `previewNodes` 指定卡片中要突出的局部节点，完整佩戴场景不受影响。
