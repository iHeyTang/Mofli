# 饰品挂载与组合

当前 Bloub 与猫猫头均声明 7 类挂载，共 20 款饰品，统一收录于 `@mofli/grove/accessories`。皮肤无需提供饰品代码；同一挂载最多一件，Studio 选新款自动替换旧款，不同挂载可组合。

| 接口 | 形式 | 内置饰品 |
| --- | --- | --- |
| `head.crown` | 头顶局部坐标系 | 鼠尾草礼帽、奶油光环、双叶新芽 |
| `head.sides` | 成对连接，`left` / `right` | 垂软兔耳、奶油小角 |
| `head.forehead` | 额头局部坐标系 / 表面 | 蜜糖宝石、奶白小花、弯月印记 |
| `head.cheeks` | 成对曲面区域 | 桃桃腮红、芝麻雀斑、星光脸贴 |
| `head.lower.front` | 下缘前侧局部坐标系 | 陶土领结、鼠尾草围巾、圆圆吊坠 |
| `head.lower.sides` | 成对连接，`left` / `right` | 双铃挂坠、奶白珠串、双侧飘带 |
| `character.orbit` | 角色中心与尺度 | 浮游泡泡、萤火微光、落英环绕 |

骨架通过 `headMounts` 输出位置、朝向、尺度、可见性和成对成员。身体转为感叹号等符号时，饰品随挂载可见性隐藏。位置采用现有头部的有界球面近似和随轮廓变化的头高、尺度，并非任意三维网格贴合。

## 饰品作者接口

新饰品使用 `defineAttachment` 声明局部场景，详见 [饰品编写指南](attachment-authoring.md)。下列 context 方法属于兼容的高级入口，内置饰品已不再直接调用：

现有 `frame` v1 增加可选的 `members` 和 `surface` 数据，原来的礼帽与领结接口兼容。

- `context.project([x,y,z])`：将挂载局部坐标投影到角色 SVG 坐标。
- `context.project([x,y,z], 'left')`：投影成组挂载中的左侧成员。右侧为 `right`，一个饰品实现同时绘制两侧。
- `context.surface([u,v], 'left')`：沿挂载的球面区域投影采样点，用于贴脸图形，避免把腮红当作悬浮平面。
- `context.time`：秒。环绕动画使用此时间，公开浏览器运行时与 `PetRegistry.create().sample(time)` 都会传入；启用 reducedMotion 时冻结为零。

使用上述投影后的绝对坐标时，饰品声明 `volume: true`，避免组合器再次应用局部矩阵。普通二维饰品仍可保持旧式局部 SVG + 挂载矩阵的实现。新饰品的 `size` 参数为 0.6–1.4；礼帽保留原悬浮高度参数。

## 分层与边界

- core 定义协议、组合、成员插值和通用投影工具，不导入任何饰品。
- 骨架声明支持的接口并逐帧提供位置与形变信息。
- 饰品定义位于 `packages/grove/src/accessories/data/*.json`，共用一个只依赖 core 的 npm 包。
- Studio 按位置分组展示款式，负责同位置替换与保存；CLI 导出包含新目录，并保留鼠标交互和环绕运动。

仍采用前景饰品 / 主动悬空的设计约束，不提供通用物体相交、实体遮挡排序或任意曲面 UV 系统。不同位置的极大饰品可能互相覆盖，组合器不会自动挪动它们。猫头本身已有耳朵，选择额外兔耳等是叠加装饰，不会删除骨架耳部。

所有包仍 private，尚未发布到 npm。

## 饰品造型

礼帽以圆润帽冠和厚帽檐的投影曲面绘制，光环采用奶油色厚圆环；其他饰品以手工定义的三次贝塞尔轮廓重绘，先在局部空间采样再投影，保持转头时的弯曲轮廓。采用奶油白、鼠尾草绿、低饱和粉与暖金的有限配色，轮廓优先，避免尖锐端点和密集碎粒。

素材库缩略图仅展示饰品；成对饰品在缩略图中缩短展示间距便于辨认，不影响实际挂载。每个位置显示自己的款式及当前尺寸控件。

## 朝向与运动

`head.sides` 的左右成员各有向外展开的局部切平面，因此转头时，两侧饰品有不同的压缩与朝向，而非两个平行贴片。它仍是有界的 2.5D 近似，非完整耳部实体模型。

铃铛、珠串、飘带、吊坠和围巾在饰品包内使用挂载根部为旋转中心，结合左右错相摆动、末端延迟和头部倾斜补偿。此处是确定性动画，不是基于头部速度的物理惯性模拟。

泡泡沿两侧上浮并淡出，萤火在局部区域停驻和短程游动，花瓣摇摆飘落；均通过 `context.time` 采样。相同时间与挂载输入得到相同结果，减弱动态模式冻结运动。
